Natours is a full-stack tour booking application built with the complete Node.js ecosystem — demonstrating production-grade backend architecture alongside a rich CSS animation-heavy frontend.

Features include JWT + cookie-based authentication, role-based access control (user/guide/admin), Stripe payment integration, server-side rendering with Pug templates, Mongoose schemas with geospatial queries, automated email via Nodemailer, file uploads with Multer, and a comprehensive error handling middleware. The CSS frontend showcases advanced animations, clip-paths, and custom-drawn SVG shapes.

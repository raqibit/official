Nexter is a premium real estate web experience built entirely with CSS Grid and vanilla HTML/CSS — demonstrating advanced layout mastery without a single JavaScript framework.

The layout features a cinematic full-bleed hero with a media trust-strip (BBC, Forbes, TechCrunch, Business Insider), six featured luxury property cards across six countries, a story section with overlapping image composition, top realtor profiles, and a stunning 14-image CSS Grid gallery. The entire layout is powered by a meticulously architected 8-column CSS Grid system following BEM methodology.
